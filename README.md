# Simple Responsive Webpage

A clean, responsive website template built with HTML, CSS, and JavaScript.

## Features

- Fully responsive design that works on all devices
- Modern, clean UI with smooth animations
- Navigation with smooth scrolling
- Image gallery with hover effects
- Contact form with basic validation
- Interactive elements with JavaScript
- Cross-browser compatible

## Getting Started

1. Clone this repository or download the files
2. Create an `images` directory and add appropriate images with the filenames mentioned above
3. Open `index.html` in your browser to view the website

## Customization

### Colors

You can easily customize the color scheme by modifying the CSS variables at the top of the `styles.css` file.

### Content

- Edit the text content in `index.html`
- Replace the images in the `images` directory with your own images
- Modify the form handling in `script.js` to send data to your backend or email service
